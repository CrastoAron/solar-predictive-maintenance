# SolarShield (Flutter)

Flutter port of the "Solar Maintenance Analysis App" (React + Vite + Tailwind).

## Run

Firebase settings are generated by FlutterFire CLI into `lib/firebase_options.dart`
and the platform config files. Those files are git-ignored; run
`flutterfire configure --project=<your-project-id>` from this directory after a
fresh checkout or when adding a platform. Enable Google under Firebase
Authentication and configure Android SHA fingerprints in Firebase Console.

Copy `.env.example` to `.env.json` for the backend URL. This file is JSON because
Flutter's `--dart-define-from-file` expects JSON; `.env.json` is git-ignored.
For ngrok, set `SOLAR_API_BASE_URL` in `.env.json` to the current HTTPS
forwarding URL, such as `https://your-tunnel.ngrok-free.app` (without an API path).

```sh
flutter pub get
flutter run --dart-define-from-file=.env.json
```
Requires Flutter 3.27+ (uses `Color.withValues`).

## Firebase and backend
Register the Android/iOS app IDs with Firebase. Use
`http://10.0.2.2:8000` for the Android emulator,
`http://localhost:8000` for an iOS simulator, or your reachable HTTPS backend URL
for a physical device/deployment. After Google sign-in, the app sends the Firebase
ID token as a Bearer token to backend routes. Service requests are sent to
`POST /api/service-requests` and stored with the signed-in customer's maintenance
history. Firebase configuration is required to sign in; the app does not provide
demo accounts or sample telemetry.

The fixed historical dataset used by Performance analysis is bundled at
`assets/cleaned_real_telemetry.csv`. Its range selectors use the most recent
timestamp in that dataset as their end date, so the analysis does not depend on
the current date or a backend connection.

## Structure
```
lib/
  main.dart
  models/      data classes (panel, summary, readings, analysis, service, slides, profile)
  services/    authentication, settings, service requests, backend data
  screens/     onboarding, main shell, home, monitoring, analysis, service, settings
  widgets/     card, badge, charts, nav, buttons, headers
  theme/       colors + dark theme
  utils/       date helpers
```
